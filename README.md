# BatchPrint Pro 智能批量打印系统

**艾瑞特科技** | www.aretes.cn | © 2026 版权所有

邮件合并功能的纯前端实现。导入 Excel 表格，将数据精准填充到自定义模板的指定位置，支持批量预览和打印。

---

## 功能特性

- **Excel 数据导入** — 自动识别表头，确认/跳过首行表头
- **毫米级精确定位** — 画布标尺 + 拖拽排版 + 十字参考线对齐提示
- **键盘微调** — 方向键 0.1mm 微调，Shift + 方向键 1mm 大步调整
- **系统字体扫描** — 自动检测系统中安装的全部字体，支持手动添加自定义字体
- **颜色精确控制** — 颜色选择器 + 十六进制文本输入联动
- **水平和垂直对齐** — 左/中/右 + 顶部/居中/底部
- **字段层级控制** — 置顶/置底按钮调整重叠字段的显示顺序
- **背景图排版参考** — 上传底图辅助对齐，打印时可选是否包含
- **模板/工程保存** — 模板（版式）和工程（版式+数据）独立存取
- **范围打印** — 指定起止行号，预览确认后再打印
- **画布缩放** — 工具栏 +/- / 适配 按钮调整工作区显示比例
- **面板折叠** — 左右侧栏可收起，释放画布空间
- **动态纸张** — A4/A5/Letter/自定义，打印时自动匹配 `@page size`
- **自动恢复** — 刷新页面后自动恢复上次工作配置

## 快速开始

### 1. 下载使用

```bash
git clone https://github.com/cqdpity-design/Batch-Template-Printing-System.git
cd Batch-Template-Printing-System
open index.html        # macOS
# 或直接用浏览器打开 index.html
```

无需安装任何依赖，纯浏览器运行。

### 2. 使用流程

```
1. 设置纸张大小（工具栏）
2. 上传背景图（可选，用于对齐参考）
3. 从左侧拖拽 Excel 字段到画布
4. 拖拽或键盘微调字段位置
5. 调整字体、字号、颜色、对齐方式
6. 导入 Excel 数据
7. 预览 → 设置打印范围 → 批量打印
```

## 技术说明

| 技术点 | 实现方式 |
|--------|----------|
| Excel 解析 | SheetJS (xlsx.js) CDN |
| 字体检测 | `document.fonts.check()` 原生 API |
| 打印分页 | `@page { size: Nmm Mmm; margin: 0 }` |
| 打印单位 | 预览用 `px`（屏幕），打印用 `mm`（物理） |
| 数据迁移 | JSON 模板/工程文件，完整自包含 |

## 注意事项

1. **打印前请取消勾选浏览器的"页眉和页脚"**，否则会打印出 URL 和页码
2. **背景图较大时**，建议压缩后再上传，避免工程文件体积过大
3. **大批量打印**（100+ 页）时，打印预览可能需要几秒加载，请耐心等待
4. **字体兼容性**：打印时使用的字体需在目标电脑上安装，否则浏览器会 fallback
